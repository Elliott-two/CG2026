Drawing filled triangles is more difficult than you might think ! Take a look at the media linked to by the buttons above (you will notice that there are a number of them - reflecting the complexity of this task). Note that you do NOT need to implement the interactive features demonstrated in the above animations - these are just for illustration purposes. You should however write a new function that takes a `CanvasTriangle` and a `Colour` as parameters and draws a suitable _filled_ triangle. 

Note that you should NOT use barycentric coordinates in this exercise - although they can be useful for determining whether or not a pixel is within the bounds of a specific triangle, this approach is inefficient for rasterising triangles. The aim of rasterising is to render a scene as quickly and as efficiently as possible - the additional computational overhead of calculating the barycentric coordinates of each pixel can really slow down rendering. 

The approach that you should take is to split each triangle in two and then calculate the start and end coordinates of each rake row (as illustrated in the slides and animations). Then create a loop to fill each pixel in the row, one at a time. It is important that you use this approach, in order to gain practical experience of the techniques in use (many of which are going to be important later on).

As well as drawing a _filled_ triangle of the specified colour, your function should also draw a **white** _stroked_ triangle over the top of it (this is to make sure that your "rasterising" is correct - both filled and stroked triangles should line up !)
